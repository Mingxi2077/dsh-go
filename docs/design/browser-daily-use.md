# 日常浏览器交互

本文件描述当前功能分支，架构见 [browser-workspace.md](browser-workspace.md)，验证结果及未测项见 [browser-validation.md](browser-validation.md)。

- 首页使用单一真实输入框，支持网址或搜索词，普通文本输入允许中文输入法；网址按规则补全协议，搜索使用所选引擎。
- 提供必应、百度、Google和DuckDuckGo选择。首页书签与网站图标可作为常用入口，图标失败时使用文字回退；历史与书签支持管理。
- 标签按主机与会话保存，每作用域最多20个、全局最多80个，首页也计入。首页作为后退节点，关闭与撤销遵循原标签归属；最多3个WebView存活，其余按需恢复。
- 标签总览显示实际网页快照，不可用时使用站点信息。快照只缓存内存，不虚构页面内容。
- 地址栏提供刷新/停止状态与鲸尾加载指示；菜单包含资料库、下载、分享、字号和系统浏览器入口。
- 整页正文或长按选区经过预览确认加入会话，独立卡片显示来源与内容，不覆盖提示词。空选区不偷换成整页，导航变化时拒绝过期提取。
- 下载管理统一目录和列表宽度、边距与滚动；空状态占据剩余空间，小屏和长路径可滚动。完成项显示实际大小；加入文件后可直接“去对话”。

普通外链默认在App内打开。DSH内部页面、插件岛、特殊协议及明确的系统浏览器操作继续使用各自入口。授权页独立于普通标签，详见 [browser-motion-refresh.md](browser-motion-refresh.md)。
