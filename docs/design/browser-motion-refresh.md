# 浏览器动效、刷新率与授权页

本文件描述已实施行为，实际设备证据与限制见 [browser-validation.md](browser-validation.md)。

## 首页及标签

首页保留同一TextField，从中央向下移动并伸展，字标/书签渐出、历史渐入。搜索态顶部为返回、“搜索”和清历史；键盘出现后平滑校正位置，收起时冻结下降中的inset，避免输入框先坠向屏底。统一渐变字标、小鲸鱼和随机提示语复用既有资源。

标签过渡使用真实网页快照缩放，不逐帧变换原生WebView。返回网页时先绘制真实页面，再完成快照放大及渐隐交接。截图、标题、图标和异步返回均检查标签及导航版本，过期结果不能替换当前页面。

网页URL左侧显示已有透明鲸尾素材，加载时播放，完成/失败时静止；页面被覆盖或应用后台时暂停。刷新按钮有明确加载状态。任务状态动画仅影响返回会话按钮。

## 刷新率

Android原生触摸/滚动与Flutter动画共同驱动刷新请求，按当前分辨率请求最高可用模式，后台释放。请求值、系统显示模式与实际帧率分别对待，不承诺始终120fps。

遵循系统和应用的减少动效配置。自动温控策略可能关闭动效；用户可以在已有性能设置中单独开启界面动效，不改系统温控或动画倍率。

## 授权页与外部网页

DeepSeek、远程、订阅及论坛授权使用独立临时页面，展示当前域名和显式系统浏览器入口，不进入普通历史、书签、引用、分享或标签截图。兼容性受站点限制，保留系统兜底，不伪造UA绕过限制。

授权绑定到对应尝试与主机，成功/取消/切换/销毁均检查归属。DeepSeek只将当前授权指定的精确loopback端口和回调路径交给引擎，state/PKCE仍由引擎校验；论坛沿用专用回调及nonce/RSA校验，不允许迟到回调覆盖新授权。

临时授权页不等于无痕，Cookie和网站存储并未按会话分区。当前设备论坛登录曾被网站拒绝，已验证系统浏览器兜底入口；其他登录与2FA完整链路仍有未测项。
